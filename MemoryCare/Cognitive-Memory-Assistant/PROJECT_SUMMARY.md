## 🚀 How to Run

### Prerequisites
- Node.js v14+ installed
- npm or yarn package manager

### Installation & Startup

```bash
# 1. Navigate to project directory
cd patient-care

# 2. Install dependencies
npm install

# 3. Start development server
npm start

# Application will open at http://localhost:3000
```

### Building for Production
```bash
npm run build
```

## 🎨 Customization

### Change Colors
Edit `src/styles/App.css` CSS variables:
```css
:root {
  --primary-color: #2E7D32;      /* Green */
  --secondary-color: #0097A7;    /* Teal */
  --accent-color: #FF6F00;       /* Orange */
  --danger-color: #D32F2F;       /* Red */
}
```

### Add New Page
1. Create `src/pages/NewPage.js`
2. Create `src/styles/NewPage.css`
3. Add route to `src/App.js`

### Change Game Rules
Edit `src/pages/GameScreen.js`:
- Modify card array
- Change scoring algorithm
- Adjust difficulty levels

## 🚨 Important Notes

### Performance
- ~50KB bundle size (uncompressed)
- Fast load time on 4G
- Smooth 60fps animations
- Optimized re-renders

### Privacy
- All data stored locally in browser
- No external API calls (by default)
- No tracking or analytics (unless configured)
- User data never sent to servers

### Security Considerations
- This is a frontend prototype
- Face login is simulated only
- No real authentication implemented
- For production, add:
  - Backend authentication
  - HTTPS only
  - Secure API calls
  - Data encryption

### Troubleshooting

**Problem: App won't start**
```bash
rm -rf node_modules package-lock.json
npm install
npm start
```

**Problem: Port 3000 in use**
```bash
npm start -- --port 3001
```

**Problem: Data not saving**
- Check browser privacy settings
- Try incognito mode
- Clear localStorage: `localStorage.clear()`
